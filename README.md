# Port-Scanner
A Python-based TCP Port Scanner designed to analyze network ports on a target host. The project uses socket programming to establish TCP connections and identify open, closed, and timed-out ports. It supports scanning a single port as well as a specified range of ports, while multithreading improves scanning efficiency and reduces overall execution time. The scanner includes a simple and user-friendly GUI for entering the target host, selecting port ranges, and viewing scan results. It also provides result logging and exception handling to ensure reliable and organized network scanning. This project demonstrates practical concepts of computer networking, TCP communication, socket programming, concurrency, multithreading, exception handling, and GUI development.
